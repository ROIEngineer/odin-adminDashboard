# 🧩 Admin Dashboard

A responsive admin dashboard layout built using **HTML** and **CSS Grid/Flexbox**. This project focuses on modern layout techniques, clean UI structure, and reusable design patterns—without any JavaScript.

---

## 📸 Preview

---

## 🚀 Features

- 📊 Dashboard-style layout with sidebar, header, and main content
- 🧭 Fixed sidebar navigation
- 🔍 Search bar and user header section
- 📁 Project cards with action icons
- 📢 Announcements panel
- 🔥 Trending section
- 🎨 Clean design using CSS variables
- 📱 Responsive layout (basic)

---

## 🛠️ Built With

- HTML5
- CSS3
  - CSS Grid
  - Flexbox
  - Custom Properties (CSS Variables)

---

## 📂 Project Structure

```
.
├── index.html     # Main HTML structure
├── styles.css     # Styling and layout
```

---

## 🧠 Key Concepts Learned

This project demonstrates:

- Structuring a full-page layout with **CSS Grid**
- Combining **Grid + Flexbox** for precise alignment
- Using `100vh` and overflow to control scrolling behavior
- Creating reusable UI components (cards, sections)
- Managing layout spacing and hierarchy
